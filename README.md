# CareWatch

A responsive, single-page website prototype for an AI smartwatch health-monitoring service. The experience demonstrates a public landing page, patient portal, health trends, alerts, doctor directory, caregiver permissions, profile settings, and a clinician dashboard.

## Run locally

Open `index.html` in a modern browser. No build step or dependencies are required. Google Fonts are loaded over the internet; system sans-serif fallbacks are provided.

## Prototype scope

- All readings, clinicians, appointments, alerts, and account details are fictional demonstration content.
- Navigation and simple controls work in the browser, but there is no login, backend, medical AI, smartwatch integration, video consultation, booking service, or persistent data storage.
- Do not enter real patient information. A production system would need secure identity and access management, consent controls, encrypted data handling, validated device integrations, clinical and regulatory review, and appropriate privacy/security safeguards.
- CareWatch is not an emergency service or a substitute for professional medical advice, diagnosis, or treatment. For an emergency, contact local emergency services.
